# Contador — Interface Software (instaladores)

Este repositório guarda apenas os instaladores do aplicativo desktop da
Área do Contador. Não há código-fonte aqui.

## Download

- **Windows 10/11 (64 bits):** [Contador.Interface.Software_x64-setup.exe](https://github.com/Interface-Softwaree/contador-app-releases/releases/latest/download/Contador.Interface.Software_x64-setup.exe)

Depois de instalar, entre com o mesmo e-mail e senha usados em
https://contadorv2.interfacesoftware.com.br.

Todas as versões estão em [Releases](https://github.com/Interface-Softwaree/contador-app-releases/releases).
